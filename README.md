JKUAT Information System

Project Description

The JKUAT Information System is a C++ based system designed to manage
students, lecturers, units and academic marks.

The system provides interaction between the Student Portal and the
Learning Management System (LMS).

Project Objectives

The main objectives of the system are:

- To allow students to register units.
- To allow students to view their registered units.
- To allow students to access learning materials through the LMS.
- To allow lecturers to manage their assigned units.
- To allow lecturers to upload notes and create assignments and CATs.
- To allow lecturers to enter student marks.
- To allow students to view their marks.
- To ensure marks entered by lecturers can be viewed by students.

System Modules

1. Student Module

Students can:

- Log into the system.
- Register units.
- View registered units.
- Access the LMS.
- View notes.
- View assignments.
- View CATs.
- View their marks.

2. Lecturer Module

Lecturers can:

- Log into the system.
- View assigned units.
- Upload notes.
- Create assignments.
- Create CATs.
- Enter student marks.

3. LMS

The LMS allows students and lecturers to interact with learning
materials and assessments.
